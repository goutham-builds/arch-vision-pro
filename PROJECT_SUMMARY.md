## 🔧 How to Get Started

### Step 1: Clone Repository
```bash
git clone https://github.com/goutham-builds/arch-vision-pro.git
cd arch-vision-pro
```

### Step 2: Install Dependencies
```bash
npm install
```

### Step 3: Run Locally
```bash
npm run dev
# Opens at http://localhost:5173
```

### Step 4: Build for Production
```bash
npm run build
```

### Step 5: Deploy
- **Vercel** (easiest): Connect GitHub repo
- **Netlify**: Drag & drop dist folder
- **GitHub Pages**: Push to gh-pages branch

## 🎨 Customization Options

### Change Colors
Edit `tailwind.config.js`:
```javascript
colors: {
  architecture: {
    dark: '#1a1a2e',
    blue: '#0f3460',
    accent: '#e94560',
    light: '#eeeeee',
    gold: '#d4af37'
  }
}
```

### Add Subjects
Edit `src/data.js` → subjects array

### Customize Game
Edit `src/data.js` → gameQuestions array

### Update Content
All content is in `src/data.js` → easy to modify
